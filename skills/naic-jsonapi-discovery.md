# Discover and query the NAIC JSON:API safely

The NAIC publishes no developer portal, no API documentation and no OpenAPI. It does serve a
complete, anonymously readable **JSON:API v1.1** surface at `https://content.naic.org/jsonapi`,
generated by Drupal 11. Everything you can learn about it, you learn from the API itself.

**Set expectations honestly:** this is an *unadvertised* public read surface. It is live and
stable in shape, but nobody has promised it will stay that way. There is no changelog, no
deprecation policy, no status page and no support channel scoped to it.

## Step 1 — Enumerate the surface: `getResourceIndex`

```
GET /jsonapi
```

The response's `links` member is the contract: one entry per exposed resource type, keyed
`entity--bundle`, with its collection URL. As of 2026-07-25 there were **284** of them.

Triage them, because most are noise:

| Family | Count | Worth your time? |
|---|---|---|
| `taxonomy_term--*` | 58 | **Yes** — model laws, insurance types, states, committees, publications, topics. The reusable classification layer. |
| `node--*` | 28 | **Yes** — articles, committee pages, the regulator directory, newsletters, CIPR research. |
| `media--*` / `file--file` | 8 | **Yes** — the published PDFs and their file URIs. |
| `paragraph--*` | 100 | No — page-composition plumbing. |
| `block_content--*`, `menu_link_content--*` | 18 | No — site chrome. |
| Drupal config entities | ~70 | No — return HTTP 200 but empty for anonymous callers. |

Re-fetch this index periodically. The content model is unversioned; the index is your only
drift detector.

## Step 2 — Learn a resource's real fields

Fetch one record with no `fields` parameter and read the actual attribute and relationship
names off it:

```
GET /jsonapi/node/article?page[limit]=1
```

Do this **before** you write a filter. Guessing a field name is the number-one cause of the
400 you are about to get.

## Step 3 — Query efficiently

Combine these on every real request:

```
GET /jsonapi/node/article
  ?fields[node--article]=title,created,field_summary     # sparse fieldsets
  &sort=-created                                          # newest first
  &filter[status]=1                                       # published only
  &page[limit]=50                                         # max page size
```

- **`fields[type]`** is not optional in practice. A default `node--article` record is ~22KB;
  three fields is ~1KB.
- **`sort`** takes a comma list, `-` prefix for descending.
- **`filter`** has a simple form `filter[field]=value` and a condition form
  `filter[label][condition][path|operator|value]=…` supporting `CONTAINS`, `STARTS_WITH`, `IN`,
  `BETWEEN`, `IS NULL` and friends.
- **`include`** side-loads relationships into a top-level `included` array —
  `?include=field_topics,field_media_document`. Use it instead of N+1 follow-up requests, but
  know that Drupal marks `include` responses `X-Drupal-Dynamic-Cache: UNCACHEABLE`, so they are
  measurably slower.

## Step 4 — Page to the end

```
page[limit]=50&page[offset]=0
```

`page[limit]` is **capped at 50** — larger values are silently clamped, so a client that asks
for 500 and assumes it got 500 will silently lose records. There is **no total count**; follow
`links.next` until it is absent.

## Step 5 — Be a good citizen

The NAIC publishes machine-consumption terms at `https://content.naic.org/llms.txt` (saved at
`llms/naic-llms.txt`):

- `crawl_delay: 10`
- `max_requests_per_day: 100`
- `allow_model_training: false`
- `require_attribution: true` → attribute as **NAIC**, link `https://content.naic.org`
- `exclude_paths: /members-only/, /user/, /private/`

**No rate limiting enforces any of this.** No 429, no `RateLimit` headers, no `Retry-After`.
The absence of enforcement is not permission. Throttle, cache (`Cache-Control: max-age=1800,
public` on collection reads), and stay inside the stated ceiling.

## Failure modes that will bite you

1. **HTML 404 on an unexposed resource type.** `GET /jsonapi/node/does_not_exist` returns
   `text/html`, not a JSON:API error — the request never reached the JSON:API router. **Check
   `content-type` before parsing.** Every other 4xx is `application/vnd.api+json`.
2. **400 on an unknown field.** "Invalid nested filtering. The field `X` … does not exist."
   Go back to step 2.
3. **404 ≠ never existed.** Unpublished and access-restricted records 404 identically to
   missing ones for anonymous callers.
4. **`virtual` is not a UUID.** Taxonomy `parent` relationships terminate in the literal id
   `virtual`, Drupal's synthetic vocabulary root. Stop traversing there.
5. **Writes are closed.** `POST` → 401 "No authentication credentials provided."; `DELETE` →
   405. There is no public credentialing path. Do not build a retry loop around it.
6. **Empty relationship arrays are normal**, not errors — an article is typically tagged into
   only two or three of its ~18 vocabularies.

## Know what is NOT here

This API carries the NAIC's **content** estate. It does not expose SERFF rate and form filings,
the Financial Data Repository's statutory statements, SBS producer licensing, OPTins premium
tax, or the Consumer Information Source. Those sit behind Okta login or behind a data-licensing
contract (`idp@naic.org`). If a task needs them, the answer is "not available via API", not a
creative query.
